# 1.2.2 — Timeline QoL fixes

**Status**: In Progress

## Overview

A batch of small quality-of-life fixes for the timeline:

1. **Effects track vertical space** — when effects stack into 2+ display rows the Effects track eats a lot of vertical space. Add a collapse toggle that condenses the whole track to a single summary bar spanning all effects; hovering lists them, clicking a name selects it and expands the track for editing.
2. **Keyframe "tail" visibility** — the lead-in ramp before each keyframe diamond faded from transparent → colour, which was too subtle. Make it a striking dashed/dotted travel line instead.
3. **Multi-select effects** — allow shift-click to select multiple effects on the Effects track (mirroring the object multi-select model). If effects are selected and the user shift-clicks a normal object, the effect selection is simply cleared (object/effect selection stay mutually exclusive).

## Task Context

- **Effects track** lives in [Timeline.tsx](src/components/Timeline.tsx): `layoutEffectRows` packs effects into display rows in **creation order** (not sorted by startTime) so rows stay stable during a drag; layout is frozen during a drag via `frozenEffectLayoutRef`. `EFFECT_ROW_HEIGHT = 26`. Effects render as amber/fuchsia envelope bars; `effectEnvelope(e)` = in+hold+out.
- **Keyframe lead-in ramps** ("tails") are drawn in [Timeline.tsx](src/components/Timeline.tsx) for both object keyframes and camera-zoom keyframes (`keyframeColor(i)` per index).
- **Selection model** ([App.tsx](src/components/App.tsx)): `selectedObjectIds: string[]` is the source of truth; `selectedObjectId` is derived (non-null only when exactly one selected). `selectedObjectId`/`selectedZoomId`/`selectedEffectId`/`selectedCaptionId` are **mutually exclusive** — selecting one clears the others. `handleSelectObject(id, additive)` toggles when `additive` (shift-click). Effects were **single-select only** (`selectedEffectId: string | null`) before this task.
- Multi-effect select mirrors the object pattern: introduce `selectedEffectIds: string[]` as source of truth, derive `selectedEffectId` for the single-selection panel. Shift-click on an effect bar toggles it in/out (no drag starts). Delete removes the whole effect selection.
- **Verification**: `npx tsc -b` must stay green (only static-check gate). Do NOT run the dev server / browser — the user tests in the browser and needs a "click X, look for Y" checklist. (See `.claude/skills/verify/SKILL.md`.)
- No em-dash in user-facing copy (use a regular hyphen).
